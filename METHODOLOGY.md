# Methodology

[Benchmark definitions](BENCHMARKS.md) own the current workload and qualification
rules. [Measurement boundaries](MEASUREMENT.md), [comparison contracts](FAIRNESS.md)
and [report conventions](REPORTING.md) describe how to apply them. Trident keeps
capability, correctness, time, memory and delivered bytes separate; it has no
combined renderer-quality score or validated production holdout.

## Artifacts and equal work

Acquire the selected catalog release before measurement and freeze its actual
payload, dependencies, public binding and runtime. Source/npm candidates use the
same explicit candidate options for every project and stay separate from release
rows. A local checkout or environment variable cannot silently substitute a build.
Mermaid's pinned reference role supplies neither an output pass nor a free score.

Adapters translate public interfaces while preserving the requested task. A missing
binding is a Trident gap; it is not proof that the product lacks a feature. APIs,
browser calls and whole CLI processes have different boundaries. Optional parser
and model APIs have their own contracts and cannot provide missing painted facts
or improve an SVG score. Product-specific source, editor and release-policy work
belongs in its owning project.

The reference installation is pinned by [tool-versions.json](tool-versions.json).
Published artifacts and original-source test runtimes retain distinct identities.
Changing a source lockfile or dependency closure requires a new prepared runtime;
an existing receipt does not become current by changing its label.

## Inputs and expected answers

Each workload names its source corpus, exact revision, extraction and selection,
licenses, duplicates and adaptations. DaveBench keeps every fenced documentation
occurrence. The terminal corpus retains project docs, tests and issue/PR
reproducers. Authored feature/model contracts retain their explicit provenance.
The public-test comparison executes unchanged original callbacks and expected
answers. Their inventories and scopes are linked from [BENCHMARKS.md](BENCHMARKS.md).

Expected drawing facts come from source intent and independently reviewed syntax,
not candidate output or agreement with a reference rendering. A source transcriber
must retain unknown constructs and conflicts. Enumerating a complete contract is
separate from proving that its observers work. Literal source values remain in
the inventory; visual contracts compare observable proportions and printed values,
not invisible database values that an image cannot distinguish.

The AM-origin community corpus is a labelled legacy regression diagnostic. Its
six timing inputs cannot support a general speed claim. Parser-only fixtures,
negative controls and positive render inputs retain separate populations. Pinned
external repository examples keep per-repository contributions; an equal file cap
does not make the resulting occurrence mix representative or balanced.

## Admission and correctness

Format/text admission establishes a usable return: for SVG, namespaced XML, a
finite canvas and authored text rather than a source echo; for PNG, decodable
pixels; for terminal output, admissible display cells. These are prerequisites,
not complete drawing verdicts. Metadata and hidden text cannot stand in for
painted labels. Literal punctuation stays literal unless the source declares
Markdown; a pie label such as `__proto__` keeps its underscores.

A correct drawing requires every planned visible fact against the actual retained
output: identities, labels, relationships, defensible directional constraints, grouping, quantities,
visibility and other declared source obligations. Missing observers stay unknown
and cannot shrink the denominator. One established violation can reject a case;
unknown checks alone cannot. Public-model facts and painted evidence remain
separate. PNG requires independently checked image content or the strict
preservation proof, not an SVG pass alone.

Unknown resources, option mappings or host setup remain setup/observation gaps.
Do not turn an untyped process exception into a syntax-rejection pass. A supported
bounded projection is not a claim to understand arbitrary CSS, filters, fonts or
every member of its diagram family. Global layout/style hints remain advisory;
hard geometric ordering needs an independently justified source constraint,
such as a simple chain or explicitly ordered tiers.

## Timing and retained evidence

The strict per-call requirements in [MEASUREMENT.md](MEASUREMENT.md) apply before
a speed ratio or better/worse claim is published. Legacy community and portable
adaptive summaries remain descriptive diagnostics even when their format/text
admission and A/A checks pass. Optional model failure does not erase a real SVG
return, but that return alone cannot qualify its time. Cache-hit, changed-source,
first-use, editing and configuration tasks have separate clocks.

Retain raw returns before grading. An observer repair normally rechecks those
bytes; it does not require another project invocation. Preserve the source,
artifact, original measurement date, old verdict and changed observer/expectation
identity. Changed sources or missing output witnesses require affected collection.
Do not grade a new contract against an old boolean or borrow another call's image.

Publish stack-ranked tables only within compatible metric, corpus, interface and
runtime groups. Keep every failure, unsupported input, unknown and unrun cell
visible. Large evidence belongs in immutable archives linked from the results
index. The [baseline](BASELINE.md) and [release process](RELEASE.md) define the
bounded harness check and packaging gates; they do not require repeating the
whole ecosystem after each change.
