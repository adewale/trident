# Changelog

## 0.1.0

Initial release of Trident as a standalone public-artifact benchmark tool.

- Seven documented benchmark suites cover public output compatibility, official
  documentation examples, authored painted meaning, public models, projected
  upstream assertions, the original reference runner and portable Node SVG cost.
- Explicit project selection, lineage/branding exclusions and no-render plans
  show scope and prerequisites before collection. Budgets stop unstarted suite
  boundaries while preserving their incomplete status.
- Portable protocol v5 translates configuration intent through reviewed public
  option paths and checks authored label font declarations. Missing bindings
  remain gaps. Output admission, model/paint evidence and timing qualification
  retain separate dispositions.
- Dated, unranked scorecards retain owning artifact identities, denominators,
  failures, raw samples, resource availability and A/A controls. Old evidence is
  never upgraded to a new measurement protocol.
- The catalog records 88 entities, including independent implementations,
  derivatives, forks, ports, bindings and integrations. Beautiful Mermaid is a
  derivative of Mermaid rather than a Git fork; Mermaid Dart is a distinct brand.
- Source and portable-kit installation paths share version 0.1.0. The kit needs
  Node 24, the actual target artifact and the pinned Mermaid oracle.
- Public output verification exercised 37 release artifacts from 42 eligible
  entries, including 16 browser transports and Ondine's public ASCII CLI.
  Six more public APIs have portable Node bindings. The support ledger retains
  missing formats, failed controls, four unbound application contracts and Rusty
  Mermaid's broken npm artifact; a source candidate remains separate.

The catalog is broader than verified execution coverage. Public documentation
and repository examples are development-exposed, with no validated production
holdout. Model observers and available runtime/format bindings vary. This release
claims no overall winner, complete Mermaid fidelity or complete neutrality.
