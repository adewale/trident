# Checking Trident

[Release checks](../RELEASE.md) are the single checklist for changed transports,
correctness and timing claims, final-head tests and packaging. The
[six-project harness profile](harness-profile.json) verifies invocation mechanisms;
it is not a comparative campaign. Ordinary commands need no Codex or model API.

[Benchmark definitions](../BENCHMARKS.md) specify tasks and corpus origins.
[RESULTS.md](../RESULTS.md) is the generated overview. The
[frozen B0 report](../docs/qualification-results-2026-10-31.md) and
[snapshot](../results/baseline.json) retain their original observer and limits.
New grading cannot rewrite those bytes or inherit their passes.

[Source audits](source-audits/) and the
[published original evidence](https://github.com/adewale/trident/blob/586bc66045cf4f1400b2d2d4aef40b525387b27f/qualification-evidence/completion-2026-10-31/README.md)
preserve the earlier inputs, outputs and verification.
