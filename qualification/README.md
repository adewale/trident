# Benchmark qualification evidence and limits

The [current minimum-cohort results](../docs/qualification-results-2026-10-31.md)
rank verified counts and retain every unknown. Complete drawing accuracy and
the initial ecosystem baseline remain unresolved. **The 0.1 release remains
blocked.**

[Published foundation evidence](https://github.com/adewale/trident/blob/79777b738e4bb5292a31b11dc405c42f6c90d323/qualification-evidence/README.md) preserves the earlier transport verification,
original failures, repairs, outputs and clocks. It remains historical. Current
retained qualification evidence is linked below. Runtime `8aa1238a` passed its
actual source/extracted-kit archive check, browser-enabled full suite, static and
regeneration checks, and Linux/macOS fixture CI. [Complete evidence and reproduction](https://github.com/adewale/trident/blob/586bc66045cf4f1400b2d2d4aef40b525387b27f/qualification-evidence/completion-2026-10-31/README.md)
include a fresh archive restore, 449 native ownership checks and 951 selected
review bindings. [Release status](../RELEASE.md)
records the exact revision, archive hash and CI run without borrowing an earlier
producer's checks.

The [six-project profile](harness-profile.json) verifies execution mechanisms.
[BASELINE.md](../BASELINE.md) explains the selection, frozen versions and budget.
It is separate from an ecosystem benchmark campaign.

The [source ledgers](source-audits/) retain reviewer roles, exact hashes and
findings. A generator reproducing its own answers is not an independent review.
The sequence author review and the separate sequence review are both retained.
SVG/PNG observer qualification is separate from a complete source transcription.

Six agents worked on evidence collection/timing, SVG, PNG, terminal, source and
release documentation, and original public tests. Authors did not supply the
only review of their own changes. Confirmed counterexamples became regression
controls; their exact affected checks and evidence remain linked. No final-head
CI or archive pass is inferred from an earlier producer.

No new whole-ecosystem campaign is justified until the advertised accuracy
claims meet the [release prerequisites](../RELEASE.md). Regrade saved bytes first.
The commands and retained tests need no Codex or model API at runtime.
