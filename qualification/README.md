# Benchmark qualification work

The implementation makes unsupported evidence visible and prevents it from
earning correctness or speed credit. It has not finished qualifying every
benchmark. **The 0.1 release remains blocked.**

The [six-project profile](harness-profile.json) verifies execution mechanisms.
[BASELINE.md](../BASELINE.md) explains the selection, frozen versions and budget.
It is separate from an ecosystem benchmark campaign.

| Plan step | Implemented | Remaining evidence or work |
|---|---|---|
| 0. Minimum cohort | Six frozen projects, 16 paths, 56 output calls and two model workflows; five-minute collection budget. | Record the assembled implementation's bounded verification result. This does not qualify full drawing accuracy. |
| 1. Safe regrading | Fresh checks replace old checks; old reports remain historical. Missing checks, wrong bindings and foreign witnesses cannot inherit a pass. | No blanket upgrade of historical results. |
| 2. Evidence records | Source, expectations, output and observer hashes; actual invocation IDs, clocks and typed outcomes. | Historical missing call clocks remain null. |
| 3. Durable collection | Raw returns precede grading; interrupted calls stay incomplete; observer retries reuse retained bytes. | A new invocation is required only when original collection is missing or invalid. |
| 4. Frozen inputs | Owned resources, explicit output/transport variants, pinned bindings and font identities. | Missing resources or unavailable bindings block the affected claim. |
| 5. DaveBench sources | All 548 occurrences retained; full source reads, per-case contracts and audit ledgers. | The [live census](../docs/docs-source-expectations.md) names unresolved source interpretations. |
| 6. SVG correctness | Owned geometry, text, routes, markers, quantities and styles; independent wrong-output controls. | The [observer matrix](../docs/svg-correctness.md) names unsupported facts and families. |
| 7. PNG correctness | Decoded-pixel identity, witnessed reviews and exact frozen SVG-conversion proof; native PNG stays separate. | Complete independent image evidence for the full native-PNG workload is absent. |
| 8. Terminal correctness | Full 120-input source audit; 81 drawing profiles with bounded projections, typed rejection controls and honest clocks. | 35 of 116 drawing profiles lack complete observers. [Offline evidence](../docs/evidence/terminal-observer-qualification-2026-10-31/README.md) preserves every unknown. |
| 9. Mermaid public tests | 41 unchanged expanded callbacks with original-source and installed-reference controls; all exclusions visible. | This diagnostic scope is not the 4,060-declaration upstream suite. |
| 10. Timing | Fixed balanced first-use schedule, fresh runtimes, per-call correctness, exhaustive causal journal, A/A controls and durable finalization. | Record a bounded production-path check; do not extrapolate one graph to ecosystem performance. |
| 11. Reports | Derived tables, best-first named metrics, shared ties, unknowns and partial-accuracy caveats. | Historical tables retain their original corpus and observer identities. |
| 12. Adversarial audit | Cross-agent source and observer reviews, substituted-output probes, ownership and timing failure injections. | Run assembled checks after integrating the confirmed fixes. |
| 13. Release | Baseline, claim prerequisites and source-versus-extracted-kit checks documented. | Full benchmark qualification and a valid initial accuracy baseline remain prerequisites. |

The [source ledgers](source-audits/) retain reviewer roles, exact hashes and
findings. A generator reproducing its own answers is not an independent review.
The sequence author review and the separate sequence review are both retained.
SVG/PNG observer qualification is separate from a complete source transcription.

Six agents worked on evidence collection/timing, SVG, PNG, terminal, source and
release documentation, and original public tests. Authors did not supply the
only review of their own changes. Confirmed counterexamples became regression
controls; they were fixed before the final integration checks.

No new whole-ecosystem campaign is justified until the advertised accuracy
claims meet the [release prerequisites](../RELEASE.md). Regrade saved bytes first.
The commands and retained tests need no Codex or model API at runtime.
