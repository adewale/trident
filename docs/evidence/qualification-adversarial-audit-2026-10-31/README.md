# Independent assembled qualification audit

This audit uses retained evidence and independently authored browser/terminal controls. It makes no renderer calls, refreshes no benchmark timings, and does not admit a source contract from a renderer's output. Audit work is isolated in `/workspace/trident-terminal-graphs`.

| Demonstrated defect | Counterexample and correction | Reviewable implementation |
| --- | --- | --- |
| SVG dash cap coverage used geometric stroke units against calibrated `pathLength` dash units | A 120 px route calibrated to 12 units with `.5 .5` dashes has visible gaps. The old observer called it solid. The inverse calibration hides gaps that the old observer counted. Actual browser pixels independently establish both cases. | `19183276f38a1606aa3bba6dd055cd8bb3eee9eb`; `tests/qualification-adversarial-audit.test.ts` |
| Adaptation replay did not match its durable start to its terminal receipt | A correct terminal-frame source identity could be paired with a different start's source/artifact/binding. Admission now requires unique matching start/outcome identities, start clocks, expected source/artifact and a matching predecessor digest when supplied. Explicit legacy missing predecessor digests remain distinct from verified digests. | `c721df39049e0f12d1c43bfa2a36d2270028d096`; `tests/terminal-adaptation-invocation-audit.test.ts` |
| A well-formed XML SVG can change paint ownership during HTML repair | A self-closing XHTML red span followed by black `Text` becomes a span containing red `Text` under `innerHTML`. Well-formed XML and unchanged dimensions therefore cannot alone transfer a PNG judgment to the original SVG. PNG owner added recursive namespace/attribute/content equivalence; the rasterized frame remains separately eligible. | PNG helper in `67eb45f`; `tests/docs-png-svg-static.test.ts` |
| A later font snapshot could retrospectively cover an older PNG call | `beginCapture` after an existing return, followed by `completeCapture([oldAttempt])`, originally succeeded. Version 2 records a pre-call journal baseline, rejects every pre-existing attempt including pending calls, binds actual start/outcome digests, and limits legacy coverage to invocation IDs in the original hashed result. | PNG-owner commits `048c41b`, `58fc36b`; additional independent controls in `tests/docs-png-capture-adversarial.test.ts` |
| Unhandled base theme variables could produce contradictory default paint obligations | Literal `theme: base` plus `primaryColor: '#ff0000'` changes derived palettes. Adding an unchanged default palette can falsely fail a correct renderer. Source owner now withholds derived paint for unqualified overrides/looks and retains their authored configuration. Independently reviewed guard and reran its nine controls; an independent [same-input comparison](canonical-palette-guard-census.json) of both functions changes none of the 546 drawing contracts in the canonical 548 entries. Other independently reviewed source changes in that commit are held fixed for this guard comparison. | Source-owner commit `2fda7299fe037bb996e4d666718c26c373b96222`; `tests/configuration-expectation.test.ts` |
| The 15 s browser race left native work running on a page reused by the next source | A controlled browser clock demonstrates a pending first render returning a harness failure at 15 s, later changing shared configuration, and contaminating the next SVG. Deadline results now carry a collector interruption, dispose their page, and reinitialize before later warmup or scored calls. A genuine native exception with the same message remains a native failure. | `9c90eb4c6301ae55c69cc1018e9a5b74c11029f3`; `tests/docs-browser-deadline-audit.test.ts` |

The exact compressed historical SVG checkpoint was decoded with `readCheckpointEntries`, validating its row hashes. Its 16 units contain 16,871 observations and 8,435 render rows. None records the inner 15 s error, host deadline, or another timeout string. [The census](retained-svg-deadline-census.json) pins both checkpoint file hashes. This particular defect establishes no affected historical rows in that collection; missing calls and absent page-epoch receipts receive no invented evidence.

Source admission and reporting checks preserve all 120 original terminal entries, the separate authored 121st adaptation, typed rejection controls, and the explicit active 116-drawing population. The ambiguous original nested-state source remains diagnostic unknown. A changed source/expectation cannot inherit a canonical grade or shrink the drawing denominator. Invalid/configuration controls cannot earn drawing credit; stale or incompatible inventories and unsupported release identities cannot be joined into a current score. Unknown terminal results withhold formal rank. PNG evidence supplies only existing unavailable planned painted checks; failed checks and uninspectable structural/resource/font/metadata/motion obligations remain present.

Validation, with overlapping suites reported separately:

- Browser deadline, existing docs transport, invalid-source and PNG assessment controls: 17 tests, 273 assertions.
- Capture version 2, independent capture mutations, static SVG transfer and owned-image conversion controls: 12 tests, 71 assertions.
- Canonical source admission, drawing populations, terminal reports, campaign reports and release identity controls: 48 tests, 768 assertions.
- Dash/pathLength, adaptation receipt, static SVG and nine-state adaptation controls: 15 tests, 103 assertions.
- Source-owner palette guard independently rerun: 9 tests, 52 assertions.

Strict TypeScript checking passes. These controls establish bounded qualification behavior, not new benchmark performance measurements or correctness credit for unknown outputs.
