# Git SVG observer qualification

This change inspects retained actual SVG geometry. It does not collect a new project output, modify a source contract, use a reference rendering as truth, or change the documentation population. The complete current source contract is still required. Boston's duplicate-identity source remains held by source admission.

The Git-specific checks in `fidelity/paint-domain-facts.ts` bind compact painted commit glyphs to independently measured branch lanes and per-lane chronology. Ordinary graphs also retain strict global source chronology; `parallelCommits:true` instead requires the documented equal-parent-depth levels. Authored IDs and tags require uniquely nearby visible owners. Generated IDs, CSS classes and model metadata do not establish identity.

Supported visible types include normal circles, nested highlight squares, crossed diagonal reverse markers, and a finite cherry-pick profile. That profile requires the two-fruit/stem geometry, its visible owned origin/selected-parent annotation, the ordinary parent, and the separate physical provenance connector. A missing or unfamiliar selected-parent encoding stays unknown. The pinned public annotation convention communicates `cherry-pick:MERGE|parent:B`; changing either identifier fails the complete source fact.

Parent checks reconstruct an exact endpoint-pair multiset, including multiplicity. Missing or extra inspectable routes fail. A glyph and its uniquely owned caption/backdrop form an endpoint compound; only that compound may cover its adjacent route interval. Thin, contrasting connectors may share one contiguous stem from the same actual glyph port. One short transverse crossing between two independently bound connectors is inspectable without inventing a new vertex. Foreign bodies, wide or parallel erasure, opaque stroke covers, masks, filters, vector effects, unfamiliar paint and unbound routes do not gain visibility credit. Each supported glyph compound also checks actual exposure of its circle/square/diagonal/fruit/stem parts. A later stroke-only cover cannot leave an invisible special marker qualified from its raw geometry. Stroke bounds include their transformed width. A stroke matching the actual host canvas or an independently painted enclosing background cannot gain credit from its mathematical geometry alone.

Branch lane, order and head checks are independent of parent/type uncertainty, but retain their own exact glyph inventory and authored identity requirements. Empty lanes do not invent native head pointers. Straight branch baselines may be SVG lines or open straight paths; recognition depends on measured lane extent and unbound endpoints. This is exercised by independent retained Mermaid and Pele outputs.

Finite authored configuration checks measure branch/commit-caption suppression, heading/lane order, rotation, parallel levels, and independently owned commit/tag paint or font leaves. Unprinted anonymous merge IDs are not fabricated to supply caption carriers. Unsupported `gitInv0` carrier ownership remains required and unknown. No default palette is asserted.
