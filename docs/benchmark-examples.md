# Worked benchmark tables

The [ecosystem results](../RESULTS.md#results-by-benchmark) are the single place
for comparative tables and charts. The retained examples use 27–28 October 2026
measurements and keep their historical qualification limits. Each table names
its ranking measure, versions, workload and units.

The [provenance receipt](evidence/benchmark-examples.json) retains the raw-source
hashes and links the immutable original receipt. Table values are maintained once
in [results/latest.json](../results/latest.json).
