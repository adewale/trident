Benchmarks stay outside CI. Product family correctness remains in product CI.
The invocation inventory also discovers the public `renderResolvedScene` API
when exported. It consumes SVG plus the complete JSON sidecars; qualification
checks their public envelope after timing. This proves that the invocation
returned usable metadata, not that every primitive has correct geometry.
Fresh-process and browser startup record this operation independently. Older
peer versions without the API retain their actual discovered surface.
Benchmark evidence remains local unless a bounded summary or reviewed image is
explicitly published. Historical archives and development dependency trees are
not publication artifacts. New protocols invalidate only the owning records;
matching unchanged project records should be reused before executing workers.

Live model evaluations need an explicit provider/model and credentials; stored
replay is a different operation. Controlled editor-ownership comparisons need
real independently produced variants. Missing evidence is never replaced with
identical pages or inferred success.

The final execution ledger and measured outcomes will be appended after the
combined implementation has passed its owning checks and timed runs complete.
