# Benchmark completion work, 27 October 2026

This work addresses the six remaining items in the preceding assessment plus
its recommendation to make corpus classification and semantic qualification
part of scoring. Results must identify their actual source revisions, execution
windows and prerequisites. The prior snapshot remains historical evidence.

| Workstream | Observable completion contract |
| --- | --- |
| Fidelity | Native meaning, owned SVG paint and decoded raster observations have independent criteria; missing projections remain explicit. Labels alone never count as complete fidelity. |
| Corpus | Parser-only, positive render and negative/diagnostic inputs retain distinct intent and pinned admission. Reports preserve raw history and expose a positive-render denominator. |
| Wider execution | Every enrolled suite has an execution or explicit prerequisite disposition; every catalog project has a record or concrete unsupported/blocked boundary. No fake model calls, hosted pages or browser outputs satisfy missing prerequisites. |
| Performance | Large and architecture work, selected optional backends, repeated controls and process-total memory have named boundaries. Unselected/ignored backends receive no timing credit; no GPU device-memory attribution is invented. |
| Product families | Event Modeling and ZenUML use real native models and render/edit contracts; source preservation is distinct from support. Each implemented construct must survive independently checked public operations. |
| Legacy work | All eleven original files reviewed and reversibly preserved; maintained owners and intentionally retired experiments are recorded in [legacy work review](legacy-work-review.md). |
| Interpretation | Correctness/coverage, latency, delivery, resources and user-supplied prices remain separate. Old clocks retain their producer identity, dates and denominator. |

Benchmarks stay outside CI. Product family correctness remains in product CI.
The invocation inventory also discovers the public `renderResolvedScene` API
when exported. It consumes SVG plus the complete JSON sidecars; qualification
checks their public envelope after timing. This proves that the invocation
returned usable metadata, not that every primitive has correct geometry.
Fresh-process and browser startup record this operation independently. Older
peer versions without the API retain their actual discovered surface.
Benchmark evidence remains local unless a bounded summary or reviewed image is
explicitly published. Historical archives and development dependency trees are
not publication artifacts. New protocols invalidate only the owning records;
matching unchanged project records should be reused before executing workers.

Live model evaluations need an explicit provider/model and credentials; stored
replay is a different operation. Controlled editor-ownership comparisons need
real independently produced variants. Missing evidence is never replaced with
identical pages or inferred success.

The final execution ledger and measured outcomes will be appended after the
combined implementation has passed its owning checks and timed runs complete.
